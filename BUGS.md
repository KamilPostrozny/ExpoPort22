# Bugs / legacy reference map

Status: navigation only. [docs/issues.md](docs/issues.md) is the current triage queue, with uncertain
implementation and device-verification status stated separately.

Old numbered bugs (§1–§7), walk reports, resolved investigations, and their evidence are preserved in
[docs/archive/issues-history.md](docs/archive/issues-history.md). Existing code comments referring to
`BUGS.md §6`, for example, mean that historical record—not a current instruction to redo the fix.

Do not treat an old "OPEN" heading as a fresh reproduction or an old Android pass as an iPhone pass.
